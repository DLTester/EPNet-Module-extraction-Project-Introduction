    Li-Fusion Framework 模块文档

    本模块定义了 EPNet 风格的 LiDAR-Image 融合框架 (Li-Fusion Framework)，
    整合了几何对齐与特征融合两个阶段，实现点云与图像的端到端特征融合。

    🌐 模块概览

    模块路径：li_fusion_framework

    核心功能包括： - 点云与图像特征提取（Backbone 模块）； - 点云到图像的几何投影； - 特征网格采样； - 特征融合（加权 + 门控 + 拼接）。

    本模块同时依赖以下子模块：

    子模块路径 作用说明
    geometry_stage.lidar_point_extractor 提取点云坐标 xyz
    geometry_stage.lidar_to_image_project 将点云投影到图像平面
    geometry_stage.grid_generator 生成归一化采样网格与有效掩码
    geometry_stage.image_sampler 按网格从图像特征图采样逐点特征
    fusion_stage.align_fusion_stage.align_fc.fc_align_p 点云特征通道对齐
    fusion_stage.align_fusion_stage.align_fc.fc_align_i 图像特征通道对齐
    fusion_stage.feature_weight_fc 特征权重生成网络
    fusion_stage.align_fusion_stage.li_fusion_add 特征相加 + tanh 激活
    fusion_stage.li_fusion_muti 特征门控乘法
    fusion_stage.li_fusion_concat 点云与图像特征拼接

    class LiDARBackbone(ABC, nn.Module):
    """
    LiDAR 特征提取骨干网络抽象基类。

    用于定义点云特征编码模块的接口。子类可使用 PointNet、PointNet++、
    PV-RCNN 等结构，将原始点云坐标映射为点级特征。

    Args:
        无。

    Forward Args:
        pointcloud (torch.Tensor): 输入点云，形状 (B, N, C≥3)。

    Returns:
        torch.Tensor: 逐点特征 (B, Dp, N)，Dp 为特征通道数。
    """
    def __init__(self):
        super().__init__()

    @abstractmethod
    def forward(self, pointcloud: torch.Tensor) -> torch.Tensor:  # pointcloud:(B,N,C>=3) 点云输入；输出逐点特征 (B,Dp,N)
        raise NotImplementedError

    抽象类，定义点云特征提取器接口，负责将点云坐标映射为逐点特征。
    用户可继承该类实现自定义点云特征网络（如 PointNet、PointNet++ 等）。

    class LIFusionCore(nn.Module):
    """
    Li-Fusion 融合核心模块。

    实现跨模态特征融合的主要逻辑，包括通道对齐、特征加和、权重生成、
    门控调制与拼接输出。

    ### 融合流程
    1. **通道对齐**：使用 `FCAlignP` / `FCAlignI` 将两模态映射到相同维度；
    2. **加和激活**：`li_fusion_add` 对齐后特征逐点相加并激活；
    3. **权重估计**：`FeatureWeightFC` 生成融合权重；
    4. **门控调制**：`li_fusion_muti` 以权重门控图像特征；
    5. **拼接输出**：`li_fusion_concat` 拼接得到最终融合特征。

    Args:
        in_p (int): 点云特征通道数。
        in_i (int): 图像特征通道数。
        fuse_d (int): 对齐后融合维度。

    Returns:
        tuple(torch.Tensor, torch.Tensor, dict):
            - **F_LI** (B, 2*fuse_d, N): 融合输出；
            - **w** (B, 1, N): 权重；
            - **cache**: 中间特征字典。
    """
    def __init__(self, in_p: int, in_i: int, fuse_d: int):  # in_p:点云特征通道数；in_i:图像特征通道数；fuse_d:融合后通道数
        super().__init__()
        self.fc_p = FCAlignP(in_p, fuse_d, use_bn=True, act=True)  # 点云通道对齐层，输入维度 in_p，输出 fuse_d
        self.fc_i = FCAlignI(in_i, fuse_d, use_bn=True, act=True)  # 图像通道对齐层，输入维度 in_i，输出 fuse_d
        self.fc_w = FeatureWeightFC(in_dim=fuse_d, out_dim=1, use_bn=False)  # 权重生成层，输入 fuse_d，输出权重 1 通道

    def forward(self, Fp: torch.Tensor, Fi_point: torch.Tensor):  # Fp:(B,Dp,N) 点云特征；Fi_point:(B,Ci,N) 图像采样特征
        Fp_ = self.fc_p(Fp)          # Fp_:(B,fuse_d,N) 点云特征经通道对齐；Fp:点云特征输入
        Fi_ = self.fc_i(Fi_point)    # Fi_:(B,fuse_d,N) 图像特征经通道对齐；Fi_point:逐点图像特征输入
        H = li_fusion_add(Fp_, Fi_, apply_tanh=True)  # H:(B,fuse_d,N) 两特征相加并激活；Fp_与Fi_为输入；apply_tanh控制是否加tanh
        w = self.fc_w(H)             # w:(B,1,N) 权重生成；H 为输入特征；输出值范围 [0,1]
        Fi_gated = li_fusion_muti(Fi_, w, sigmoid_y=False)  # Fi_gated:(B,fuse_d,N) 图像特征门控结果；Fi_:输入特征；w:权重
        F_LI = torch.ops.li_fusion.concat([Fp_, Fi_gated], 1)       # F_LI:(B,2*fuse_d,N) 拼接融合结果；Fp_与Fi_gated在通道维拼接
        return F_LI, w, {"Fp_": Fp_, "Fi_": Fi_, "H": H, "Fi_gated": Fi_gated}  # 返回融合特征F_LI、权重w及中间缓存

    实现点云与图像特征的跨模态融合逻辑。
    内部结构包括： - FCAlignP / FCAlignI：通道对齐； - li_fusion_add：跨模态相加 + tanh； - FeatureWeightFC：融合权重生成； - li_fusion_muti：特征门控； - li_fusion_concat：拼接输出。

    输出： - 融合特征 F_LI； - 权重图 w； - 中间缓存字典（包含 Fp_, Fi_, H, Fi_gated）。

    class LIFusionPipeline(nn.Module):
    """
    Li-Fusion 端到端融合管线。

    该类将几何投影、图像采样、两模态特征提取与融合统一为可训练流水线，
    可直接用于下游检测或语义分割任务。

    ### 前向流程
    1. 从点云中提取 xyz 坐标；
    2. 利用相机外内参 `(R, t, K)` 将点云投影至图像平面；
    3. 生成采样网格与有效掩码；
    4. 从图像特征图上采样逐点特征；
    5. 调用 Li-Fusion 核心模块进行融合。

    Args:
        lidar_backbone (LiDARBackbone): 点云特征提取器。
        image_backbone (ImageBackbone): 图像特征提取器。
        fuse_d (int): 融合中间维度。

    Returns:
        dict:
            - **F_LI** (B, 2*fuse_d, N): 融合特征；
            - **w** (B, 1, N): 权重；
            - **mask** (B, N): 有效点掩码；
            - 以及中间缓存特征 (`Fp_`, `Fi_`, `H`, `Fi_gated`)。
    """
    def __init__(self, lidar_backbone: LiDARBackbone, image_backbone: ImageBackbone, fuse_d: int):
        super().__init__()
        self.lidar_backbone = lidar_backbone  # lidar_backbone: LiDAR 特征提取模块对象
        self.image_backbone = image_backbone  # image_backbone: 图像特征提取模块对象
        self.fuse_d = fuse_d                  # fuse_d: 融合通道数（控制中间维度）
        self._fusion_core: Optional[LIFusionCore] = None  # _fusion_core: 延迟构建的融合模块实例

    def _build_fusion_if_needed(self, Fp: torch.Tensor, Fi_point: torch.Tensor):  # Fp:(B,Dp,N) 点云特征；Fi_point:(B,Ci,N) 图像特征
        """根据输入特征的通道数动态构建融合核心。"""
        if self._fusion_core is None:  # 检查是否已经初始化融合核心
            in_p = Fp.shape[1]  # in_p: 点云特征通道 Dp
            in_i = Fi_point.shape[1]  # in_i: 图像特征通道 Ci
            self._fusion_core = LIFusionCore(in_p=in_p, in_i=in_i, fuse_d=self.fuse_d).to(Fp.device)  # 构建融合核心并迁移至设备

    def forward(self, pointcloud: torch.Tensor, image: torch.Tensor,
                R: torch.Tensor, t: torch.Tensor, K: torch.Tensor):  # pointcloud:(B,N,C>=3)；image:(B,3,H,W)；R/t/K:相机参数
        """执行完整的 Li-Fusion 前向计算流程。"""
        B, _, H, W = image.shape  # B:批大小；H:图像高；W:图像宽；_:通道数3

        xyz = lidar_point_extractor(pointcloud)                    # xyz:(B,N,3) 提取点云坐标；pointcloud为输入
        uv, depth, _M = lidar_to_image_projector(xyz, R, t, K)     # uv:(B,N,2) 图像坐标；depth:(B,N,1) 深度；R/t/K:相机外内参
        _xy_norm, grid, mask = grid_generator(W, H, uv, depth)  # grid:(B,1,N,2) 归一化采样网格；mask:(B,N) 有效掩码

        fmap = self.image_backbone(image)                          # fmap:(B,Ci,H,W) 图像特征图；image为输入
        Fi_point = image_sampler(fmap, grid)                       # Fi_point:(B,Ci,N) 采样点特征；fmap:特征图；grid:采样坐标
        Fp = self.lidar_backbone(pointcloud)                       # Fp:(B,Dp,N) 点云特征；pointcloud:输入点云

        self._build_fusion_if_needed(Fp, Fi_point)                 # 若首次执行则构建融合核心；Fp/Fi_point用于确定通道数
        F_LI, w, cache = self._fusion_core(Fp, Fi_point)           # F_LI:(B,2*fuse_d,N) 融合输出；w:(B,1,N) 权重；cache:中间特征字典

        return {"F_LI": F_LI, "w": w, "mask": mask, **cache}       # 返回融合特征F_LI、权重w、mask及缓存特征
