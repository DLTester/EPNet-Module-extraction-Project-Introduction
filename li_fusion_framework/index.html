Li-Fusion Framework 模块文档¶

本模块定义了 EPNet 风格的 LiDAR-Image 融合框架 (Li-Fusion Framework)，
整合了几何对齐与特征融合两个阶段，实现点云与图像的端到端特征融合。

模块概览¶

模块路径：li_fusion_framework

核心功能包括： - 点云与图像特征提取（Backbone 模块）； - 点云到图像的几何投影； - 特征网格采样； - 特征融合（加权 + 门控 + 拼接）。

本模块同时依赖以下子模块：

子模块路径 作用说明
geometry_stage.lidar_point_extractor 提取点云坐标 xyz
geometry_stage.lidar_to_image_project 将点云投影到图像平面
geometry_stage.grid_generator 生成归一化采样网格与有效掩码
geometry_stage.image_sampler 按网格从图像特征图采样逐点特征
fusion_stage.align_fusion_stage.align_fc.fc_align_p 点云特征通道对齐
fusion_stage.align_fusion_stage.align_fc.fc_align_i 图像特征通道对齐
fusion_stage.feature_weight_fc 特征权重生成网络
fusion_stage.align_fusion_stage.li_fusion_add 特征相加 + tanh 激活
fusion_stage.li_fusion_muti 特征门控乘法
fusion_stage.li_fusion_concat 点云与图像特征拼接

class LIFusionCore(nn.Module):
    """
    Li-Fusion 核心融合模块：
    对齐点云和图像通道后执行加权融合。
    """

    def __init__(self, in_p: int, in_i: int, fuse_d: int):
        """
        Args:
            in_p (int): 点云特征通道数。
            in_i (int): 图像特征通道数。
            fuse_d (int): 融合后目标通道数。
        """
        super().__init__()
        self.fc_p = FCAlignP(in_p, fuse_d, use_bn=True, act=True)      # 点云通道对齐层
        self.fc_i = FCAlignI(in_i, fuse_d, use_bn=True, act=True)      # 图像通道对齐层
        self.fc_w = FeatureWeightFC(in_dim=fuse_d, out_dim=1, use_bn=False)  # 权重生成层

    def forward(self, Fp: torch.Tensor, Fi_point: torch.Tensor):
        """
        执行跨模态融合。

        Args:
            Fp (torch.Tensor): 点云特征，形状 (B, Dp, N)。
            Fi_point (torch.Tensor): 图像采样特征，形状 (B, Ci, N)。

        Returns:
            Tuple[torch.Tensor, torch.Tensor, dict]:
                - **F_LI**: 融合特征 (B, 2*fuse_d, N)
                - **w**: 权重 (B, 1, N)
                - **cache**: 中间结果缓存字典
        """
        Fp_ = self.fc_p(Fp)                      # 点云特征通道对齐
        Fi_ = self.fc_i(Fi_point)                # 图像特征通道对齐
        H = li_fusion_add(Fp_, Fi_, apply_tanh=True)   # 融合特征相加 + 激活
        w = self.fc_w(H)                         # 生成融合权重
        Fi_gated = li_fusion_muti(Fi_, w, sigmoid_y=False)  # 权重门控图像特征
        F_LI = li_fusion_concat([Fp_, Fi_gated], 1)        # 拼接融合输出
        return F_LI, w, {"Fp_": Fp_, "Fi_": Fi_, "H": H, "Fi_gated": Fi_gated}

class LIFusionPipeline(nn.Module):
    """
    Li-Fusion 融合流程管线：
    负责几何映射、特征提取与融合执行。
    """

    def __init__(self, lidar_backbone: LiDARBackbone, image_backbone: ImageBackbone, fuse_d: int):
        """
        Args:
            lidar_backbone (LiDARBackbone): 点云特征提取模块。
            image_backbone (ImageBackbone): 图像特征提取模块。
            fuse_d (int): 融合特征维度。
        """
        super().__init__()
        self.lidar_backbone = lidar_backbone
        self.image_backbone = image_backbone
        self.fuse_d = fuse_d
        self._fusion_core: Optional[LIFusionCore] = None

    def _build_fusion_if_needed(self, Fp: torch.Tensor, Fi_point: torch.Tensor):
        """
        根据输入动态构建融合核心。

        Args:
            Fp (torch.Tensor): 点云特征 (B, Dp, N)。
            Fi_point (torch.Tensor): 图像特征 (B, Ci, N)。
        """
        if self._fusion_core is None:
            in_p = Fp.shape[1]
            in_i = Fi_point.shape[1]
            self._fusion_core = LIFusionCore(in_p=in_p, in_i=in_i, fuse_d=self.fuse_d).to(Fp.device)

    def forward(self, pointcloud: torch.Tensor, image: torch.Tensor,
                R: torch.Tensor, t: torch.Tensor, K: torch.Tensor):
        """
        执行完整的 Li-Fusion 前向流程。

        Args:
            pointcloud (torch.Tensor): 点云输入 (B, N, C>=3)。
            image (torch.Tensor): 图像输入 (B, 3, H, W)。
            R (torch.Tensor): 相机旋转矩阵。
            t (torch.Tensor): 相机平移向量。
            K (torch.Tensor): 相机内参矩阵。

        Returns:
            dict: 输出字典，包括：
                - **F_LI**: 融合特征 (B, 2*fuse_d, N)
                - **w**: 融合权重 (B, 1, N)
                - **mask**: 有效点掩码
                - 以及中间缓存特征
        """
        B, _, H, W = image.shape
        xyz = lidar_point_extractor(pointcloud)
        uv, depth, _M = lidar_to_image_projector(xyz, R, t, K)
        _xy_norm, grid, mask = grid_generator(W, H, uv, depth)
        fmap = self.image_backbone(image)
        Fi_point = image_sampler(fmap, grid)
        Fp = self.lidar_backbone(pointcloud)

        self._build_fusion_if_needed(Fp, Fi_point)
        F_LI, w, cache = self._fusion_core(Fp, Fi_point)
        return {"F_LI": F_LI, "w": w, "mask": mask, **cache}
