    Fusion Stage 模块

    模块说明

    融合阶段（Fusion Stage）负责点云与图像特征的跨模态融合。 其主要功能包括特征对齐、特征加权与融合操作。

    本阶段包含以下子模块：

    • li_fusion_add — 特征相加并可选 tanh 激活；
    • li_fusion_muti — 特征门控/加权乘法；
    • li_fusion_concat — 通道拼接融合；
    • feature_weight_fc — 通道注意力权重计算；
    • align_fusion_stage — 点云与图像对齐模块：
    • fc_align_i — 图像通道对齐；
    • fc_align_p — 点云通道对齐。

    li_fusion_add(Fp, Fi, apply_tanh=True)

    Li-Fusion Add（逐元素加法 + 可选 tanh 激活）

    将两路对齐后的逐点特征（通常为点云支路 Fp 与图像支路 Fi）进行逐元素相加； 若 apply_tanh=True，在加法结果上施加 tanh 激活以增强非线性与数值稳定性。 本算子无可学习参数，是 Li-Fusion 中“Add + tanh”步骤的基础融合算子。

    参数 (Args)

    • Fp (torch.Tensor): 第一输入张量，形状 (B, D, N)，通常为点云分支对齐后的特征。

    • Fi (torch.Tensor): 第二输入张量，形状 (B, D, N)，通常为图像分支对齐后的特征。

      要求与 Fp 形状一致；如使用广播，请确保语义正确。

    • apply_tanh (bool, default=True): 是否在加法结果上应用 tanh 激活（输出约束在 [-1, 1]）。

    返回 (Returns)
    • torch.Tensor: 融合后的输出特征，形状 (B, D, N)；返回前会 clone()，避免与输入共享内存（满足自定义算子约束）。
    说明 (Notes)
    • 该算子假设 Fp 与 Fi 已完成通道维度对齐（例如通过 FCAlignP/FCAlignI）。
    • 若需更强的稳定性，可考虑在上游加入归一化或在本算子后加入正则化。
    • 为满足 torch.library.custom_op 返回不与输入别名的要求，输出使用 clone()。

    @torch.library.custom_op("li_fusion::add_tanh", mutates_args=[])
def li_fusion_add(Fp: torch.Tensor, Fi: torch.Tensor, apply_tanh: bool = True) -> torch.Tensor:
    """
    Li-Fusion Add（逐元素加法 + 可选 tanh 激活）
    ==========================================

    将两路对齐后的逐点特征（通常为点云支路 `Fp` 与图像支路 `Fi`）进行逐元素相加；
    若 `apply_tanh=True`，在加法结果上施加 `tanh` 激活以增强非线性与数值稳定性。
    本算子无可学习参数，是 Li-Fusion 中“Add + tanh”步骤的基础融合算子。

    ---
    ### 参数 (Args)
    - **Fp** (`torch.Tensor`):
      第一输入张量，形状 `(B, D, N)`，通常为点云分支对齐后的特征。

    - **Fi** (`torch.Tensor`):
      第二输入张量，形状 `(B, D, N)`，通常为图像分支对齐后的特征。
      > 要求与 `Fp` **形状一致**；如使用广播，请确保语义正确。

    - **apply_tanh** (`bool`, default=`True`):
      是否在加法结果上应用 `tanh` 激活（输出约束在 `[-1, 1]`）。

    ---
    ### 返回 (Returns)
    - `torch.Tensor`:
      融合后的输出特征，形状 `(B, D, N)`；返回前会 `clone()`，避免与输入共享内存（满足自定义算子约束）。

    ---
    ### 说明 (Notes)
    - 该算子假设 `Fp` 与 `Fi` 已完成**通道维度对齐**（例如通过 `FCAlignP`/`FCAlignI`）。
    - 若需更强的稳定性，可考虑在上游加入归一化或在本算子后加入正则化。
    - 为满足 `torch.library.custom_op` 返回不与输入别名的要求，输出使用 `clone()`。

    """
    out = Fp + Fi
    if apply_tanh:
        out = torch.tanh(out)
    return out.clone()  # 避免 alias 报错

    li_fusion_muti(x, y, sigmoid_y=False)

    Li-Fusion Multiply（门控加权算子）

    对输入特征 x 与权重 y 逐元素相乘，实现特征加权或门控（Gating）。 当 sigmoid_y=True 时，对 y 执行 Sigmoid 压缩，使其取值范围限制在 [0, 1]， 从而模拟可学习的“特征开关”机制。

    功能说明
    • 输入主特征 x（通常为图像特征）与权重图 y；
    • 若启用 sigmoid_y，则先将 y 映射至 [0,1]；
    • 输出经门控调制的特征：out = x * y。
    参数 (Args)
    • x (torch.Tensor): 主特征张量。 形状 (B, D, N)
    • B: batch 大小
    • D: 特征通道数

    • N: 点数或像素数

    • y (torch.Tensor): 权重/门控张量。 形状 (B, 1, N) 或可广播到 (B, D, N)。 通常由 FeatureWeightFC 输出。

    • sigmoid_y (bool, default=False): 是否对 y 进行 Sigmoid 激活。

    • True: 执行 y = sigmoid(y)
    • False: 直接使用原始权重
    输出 (Returns)
    • out (torch.Tensor): 逐元素乘法后的输出特征，形状 (B, D, N)。 表示经门控调制后的主特征（图像或点云）。
    数学公式 (Formula)

    对每个点特征 x_i 与权重 y_i：

    if sigmoid_y:
    y_i = σ(y_i)
out_i = x_i * y_i

    其中 σ(·) 表示 Sigmoid 函数。

    @torch.library.custom_op("li_fusion::multiply_gate", mutates_args=[])
def li_fusion_muti(x: torch.Tensor, y: torch.Tensor, sigmoid_y: bool = False) -> torch.Tensor:
    """
    Li-Fusion Multiply（门控加权算子）
    =================================

    对输入特征 `x` 与权重 `y` 逐元素相乘，实现特征加权或门控（Gating）。
    当 `sigmoid_y=True` 时，对 `y` 执行 Sigmoid 压缩，使其取值范围限制在 `[0, 1]`，
    从而模拟可学习的“特征开关”机制。

    ---
    ### 功能说明
    - 输入主特征 `x`（通常为图像特征）与权重图 `y`；
    - 若启用 `sigmoid_y`，则先将 `y` 映射至 `[0,1]`；
    - 输出经门控调制的特征：`out = x * y`。

    ---
    ### 参数 (Args)
    - **x** (`torch.Tensor`):
      主特征张量。
      形状 `(B, D, N)`
      - `B`: batch 大小
      - `D`: 特征通道数
      - `N`: 点数或像素数

    - **y** (`torch.Tensor`):
      权重/门控张量。
      形状 `(B, 1, N)` 或可广播到 `(B, D, N)`。
      通常由 `FeatureWeightFC` 输出。

    - **sigmoid_y** (`bool`, default=`False`):
      是否对 `y` 进行 Sigmoid 激活。
      - `True`: 执行 `y = sigmoid(y)`
      - `False`: 直接使用原始权重

    ---
    ### 输出 (Returns)
    - **out** (`torch.Tensor`):
      逐元素乘法后的输出特征，形状 `(B, D, N)`。
      表示经门控调制后的主特征（图像或点云）。

    ---
    ### 数学公式 (Formula)
    对每个点特征 `x_i` 与权重 `y_i`：
    ```
    if sigmoid_y:
        y_i = σ(y_i)
    out_i = x_i * y_i
    ```
    其中 `σ(·)` 表示 Sigmoid 函数。

    """
    if sigmoid_y:
        y = torch.sigmoid(y)
    out = x * y
    return out.clone()

    Li-Fusion Concat（跨模态特征拼接算子）

    将多路特征张量（如点云特征 F_P 与门控后的图像特征 F_Ig） 沿指定维度拼接，形成联合的跨模态表示。 通常作为 Li-Fusion 模块融合阶段的最后一步， 用于生成最终融合特征 F_LI。

    功能说明

    • 沿指定维度（默认通道维 dim=1）拼接；
    • 输出联合特征张量 (B, D_sum, N)，其中 D_sum = Σ D_i。
    参数 (Args)
    • tensors (List[torch.Tensor]): 输入特征列表，每个元素形状相同（除拼接维度外）。 常见输入：
    • F_P : 点云特征 (B, D_p, N)

    • F_Ig : 门控后的图像特征 (B, D_i, N)

    • dim (int, default=1): 拼接维度索引。 通常取 1，表示通道维拼接。

    输出 (Returns)
    • out (torch.Tensor): 拼接后的输出特征，形状 (B, D_sum, N) 其中 D_sum = D_p + D_i，代表融合后的通道总数。

    F_out = Concat(F₁, F₂, …, Fₖ, dim=1)

    例如：

    @torch.library.custom_op("li_fusion::concat", mutates_args=[])
def li_fusion_concat(tensors: List[torch.Tensor], dim: int = 1) -> torch.Tensor:
    """
    Li-Fusion Concat（跨模态特征拼接算子）
    =====================================

    将多路特征张量（如点云特征 `F_P` 与门控后的图像特征 `F_Ig`）
    沿指定维度拼接，形成联合的跨模态表示。
    通常作为 Li-Fusion 模块融合阶段的**最后一步**，
    用于生成最终融合特征 `F_LI`。

    ---
    ### 功能说明
    - 输入多路模态特征（点云 / 图像 / 权重调制后特征）；
    - 沿指定维度（默认通道维 `dim=1`）拼接；
    - 输出联合特征张量 `(B, D_sum, N)`，其中 `D_sum = Σ D_i`。

    ---
    ### 参数 (Args)
    - **tensors** (`List[torch.Tensor]`):
      输入特征列表，每个元素形状相同（除拼接维度外）。
      常见输入：
      - `F_P`  : 点云特征 `(B, D_p, N)`
      - `F_Ig` : 门控后的图像特征 `(B, D_i, N)`

    - **dim** (`int`, default=`1`):
      拼接维度索引。
      通常取 `1`，表示通道维拼接。

    ---
    ### 输出 (Returns)
    - **out** (`torch.Tensor`):
      拼接后的输出特征，形状 **(B, D_sum, N)**
      其中 `D_sum = D_p + D_i`，代表融合后的通道总数。

    ---
    ### 数学描述 (Formula)
    对于输入特征序列 `{F₁, F₂, …, Fₖ}`：
    ```
    F_out = Concat(F₁, F₂, …, Fₖ, dim=1)
    ```
    例如：
    ```
    F_LI = Concat(F_P, F_Ig, dim=1)
    ```

    """
    return torch.cat(tensors, dim=dim).clone()

    FeatureWeightFC 算子（权重图生成层）

    【功能说明】 该算子用于在 Li-Fusion 模块中，根据融合特征 H 生成逐点权重图 w。 其核心操作为一层 1×1 卷积（等价于逐点全连接）， 用于将高维融合特征映射到单通道权重空间， 再通过 Sigmoid 激活函数将输出压缩到 [0, 1] 范围， 以表示每个点或像素的置信度或重要性。

    【输入参数】 in_dim : int 输入特征维度，对应融合特征 H 的通道数。

    out_dim : int，默认 1
    输出特征维度，通常为 1，表示输出单通道权重图。

use_bn : bool，默认 False
    是否在卷积后使用 Batch Normalization，用于数值稳定。

    【输入】 H : torch.Tensor 融合特征张量 - 形状：(B, D, N) B：batch 大小 D：输入通道数，对应 in_dim N：点数或采样点数量

    【输出】 w : torch.Tensor 权重图张量 - 形状：(B, 1, N) 表示每个点的权重值，范围 [0, 1] - 通过 Sigmoid 压缩得到，越接近 1 表示权重越高。

    【作用说明】 该算子对应论文中的 “FC + Sigmoid” 步骤， 在融合结构中用于生成特征加权系数， 使网络能自适应地调整 LiDAR 与图像特征的贡献比例。

    class FeatureWeightFC(nn.Module):
    """
    FeatureWeightFC 算子（权重图生成层）
    ----------------------------------
    【功能说明】
        该算子用于在 Li-Fusion 模块中，根据融合特征 H 生成逐点权重图 w。
        其核心操作为一层 1×1 卷积（等价于逐点全连接），
        用于将高维融合特征映射到单通道权重空间，
        再通过 Sigmoid 激活函数将输出压缩到 [0, 1] 范围，
        以表示每个点或像素的置信度或重要性。

    【输入参数】
        in_dim : int
            输入特征维度，对应融合特征 H 的通道数。

        out_dim : int，默认 1
            输出特征维度，通常为 1，表示输出单通道权重图。

        use_bn : bool，默认 False
            是否在卷积后使用 Batch Normalization，用于数值稳定。

    【输入】
        H : torch.Tensor
            融合特征张量
            - 形状：(B, D, N)
              B：batch 大小
              D：输入通道数，对应 in_dim
              N：点数或采样点数量

    【输出】
        w : torch.Tensor
            权重图张量
            - 形状：(B, 1, N)
              表示每个点的权重值，范围 [0, 1]
            - 通过 Sigmoid 压缩得到，越接近 1 表示权重越高。

    【作用说明】
        该算子对应论文中的 “FC + Sigmoid” 步骤，
        在融合结构中用于生成特征加权系数，
        使网络能自适应地调整 LiDAR 与图像特征的贡献比例。
    """
    def __init__(self, in_dim, out_dim=1, use_bn=False):
        super().__init__()
        layers = [nn.Conv1d(in_dim, out_dim, 1, bias=not use_bn)]
        if use_bn:
            layers.append(nn.BatchNorm1d(out_dim))
        self.fc = nn.Sequential(*layers)

    def forward(self, H: torch.Tensor) -> torch.Tensor:
        w = self.fc(H)
        w = torch.sigmoid(w)
        return w

    FCAlignI（图像特征通道对齐层）

    将图像支路的逐点特征 F_I (B, C_i, N) 通过 1×1 卷积映射到统一维度 D， 以便与 LiDAR 特征 F_P (B, D_p, N) 在后续融合阶段进行模态对齐。

    功能说明

    本算子对应于 Li-Fusion 框架中 “FC (Image Branch)” 模块的第一步： - 接收图像分支的采样特征 F_I； - 将其通道维度从 C_i 映射至融合维度 D； - 输出结果与点云特征在维度上对齐，用于后续的逐元素加法融合（li_fusion_add）。

    该层可选使用 BatchNorm 与 ReLU，以增强非线性表达与稳定训练。

    参数（Args）

    • in_i (int): 输入通道数（图像特征维度 C_i）。

    • out_d (int): 输出通道数（目标维度 D），应与点云分支对齐后的特征通道一致。

    """
    FCAlignI（图像特征通道对齐层）
    ==============================

    将图像支路的逐点特征 `F_I (B, C_i, N)` 通过 1×1 卷积映射到统一维度 `D`，
    以便与 LiDAR 特征 `F_P (B, D_p, N)` 在后续融合阶段进行模态对齐。

    ### 功能说明
    本算子对应于 Li-Fusion 框架中 “**FC (Image Branch)**” 模块的第一步：
    - 接收图像分支的采样特征 `F_I`；
    - 将其通道维度从 `C_i` 映射至融合维度 `D`；
    - 输出结果与点云特征在维度上对齐，用于后续的逐元素加法融合（`li_fusion_add`）。

    该层可选使用 BatchNorm 与 ReLU，以增强非线性表达与稳定训练。

    ---
    ### 参数（Args）
    - **in_i** (`int`):
      输入通道数（图像特征维度 `C_i`）。

    - **out_d** (`int`):
      输出通道数（目标维度 `D`），应与点云分支对齐后的特征通道一致。

    - **use_bn** (`bool`, default=`True`):
      是否启用 Batch Normalization。启用后有助于训练收敛与特征分布稳定。

    - **act** (`bool`, default=`True`):
      是否在卷积后添加 ReLU 激活函数，用于增强非线性建模能力。

    ---
    ### 输入（Input）
    - **Fi** (`torch.Tensor`):
      图像分支采样特征，形状 **(B, C_i, N)**
      - `B`: 批大小
      - `C_i`: 图像特征通道数
      - `N`: 点或像素采样数量

    ---
    ### 输出（Output）
    - **out** (`torch.Tensor`):
      通道对齐后的图像特征，形状 **(B, D, N)**
      其中 `D` 为融合维度，对齐到点云特征通道数。

    ---
    ### 数学关系（Formula）
    对每个点特征 `f_i ∈ ℝ^{C_i}`：
    ```
    f'_i = ReLU(BN(W · f_i + b))     # 若启用 BN + ReLU
    ```
    其中 `W` 为 1×1 卷积的权重矩阵。

    ---
    ### 典型用途
    ```python

    Fi_aligned = align_i(Fi)  # (B, 128, N)
    ```
    该输出 `Fi_aligned` 通常直接进入：
    ```python
    H = li_fusion_add(Fp_aligned, Fi_aligned, apply_tanh=True)
    ```
    用于跨模态特征融合。
    """
    def __init__(self, in_i: int, out_d: int, use_bn: bool = True, act: bool = True):
        super().__init__()
        layers = [nn.Conv1d(in_i, out_d, 1, bias=not use_bn)]

        self.net = nn.Sequential(*layers)

    def forward(self, Fi: torch.Tensor) -> torch.Tensor:
