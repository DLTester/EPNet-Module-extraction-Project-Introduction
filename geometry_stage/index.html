    Geometry Stage 模块

    模块简介

    Geometry Stage（几何阶段）是 Li-Fusion 框架的第一阶段，负责将 LiDAR 点云与图像在几何空间上对齐。
    该阶段由一系列自定义算子（Custom Ops）组成，完成从三维点到二维像素的映射，为后续融合阶段提供特征级对齐的数据基础。

    模块结构

    算子名称 功能说明
    lidar_point_extractor 从点云中提取 (x, y, z) 三维坐标。
    lidar_to_image_projector 利用相机外参 (R, t) 与内参 (K) 将 LiDAR 点投影到图像平面，生成像素坐标 (u, v) 与深度 depth。
    grid_generator 将像素坐标 (u, v) 转换为 grid_sample 可用的归一化采样网格 grid，并生成有效点掩码 mask。
    image_sampler 根据采样网格 grid，在图像特征图上执行双线性插值采样，提取逐点图像特征，实现点云-图像对齐。

    这些算子共同完成以下数据流：

    LiDAR点云 → (提取坐标) → lidar_point_extractor → (投影至图像平面) → lidar_to_image_projector → (生成归一化网格) → grid_generator → (采样图像特征) → image_sampler

    输出结果包括： - 对齐后的像素坐标 uv - 深度图 depth - 有效掩码 mask - 对应的逐点图像特征 Fi_point

    @torch.library.custom_op("li_fusion::lidar_point_extractor", mutates_args=[])
def lidar_point_extractor(pointcloud: torch.Tensor) -> torch.Tensor:
    """
    LiDAR Point Extractor（点云坐标提取算子）
    ========================================

    从输入的点云张量中提取前三个通道 `(x, y, z)`，得到仅包含三维坐标的子张量，
    作为 Li-Fusion 几何阶段后续模块（如 `lidar_to_image_projector`）的输入。

    该算子属于 **Li-Fusion 几何阶段 (Geometry Stage)** 的第一步，
    用于从原始点云特征中分离出几何信息部分。

    ---
    ### 🧩 输入参数

    参数（Args）:
        pointcloud (torch.Tensor):
            点云输入张量，形状为 `(B, N, C)`。
            - **B**：batch 大小
            - **N**：点数（每帧点云中包含的点数量）
            - **C**：点云通道数（≥3，一般为 `[x, y, z, intensity, ...]`）

    ---
    ### 📤 输出结果

    返回（Returns）:
        torch.Tensor:
            形状 `(B, N, 3)` 的坐标张量，仅保留前三个通道 `(x, y, z)`，
            用于后续的投影、采样与跨模态融合。

    ---
    ### ⚙️ 处理逻辑

    - 从输入中切片提取前 3 个维度；
    - 使用 `.contiguous().clone()` 确保输出内存连续，避免后续梯度计算时的警告；
    - 算子无状态，不改变输入，仅返回新张量。

    ---
    ### 🧠 示例

    ```python
    xyz = torch.ops.li_fusion.lidar_point_extractor(pointcloud)
    print(xyz.shape)   # (B, N, 3)
    ```

    ---
    ### 📌 注意事项

    - 输入的点云必须包含至少三个通道（x, y, z）；
    - 该算子仅做数据切片，不对数值做归一化；
    - 在 Li-Fusion Pipeline 中的典型调用序列为：
      ```
      xyz = lidar_point_extractor(pointcloud)
      uv, depth, _ = lidar_to_image_projector(xyz, R, t, K)
      ```
    """
    xyz = pointcloud[..., 0:3].contiguous().clone()  # 提取 (x, y, z)，保持内存连续
    return xyz

    2. lidar_to_image_projector

    根据相机参数 (R, t, K) 计算点云在图像平面的投影结果。

    lidar_to_image_projector(lidar_points, R, t, K)

    LiDAR → Image Projector（点云到图像投影算子）

    将 LiDAR 三维点 (x, y, z) 投影到图像平面，依据相机外参 R,t 与内参 K 计算： - 像素坐标 uv（单位：像素）； - 深度 depth（相机坐标系下 Z 值）； - 投影矩阵 M = K [R | t]（3×4）。

    本算子属于 Li-Fusion 几何阶段 的核心步骤，通常与 grid_generator()、image_sampler() 联用：

    uv, depth, M = lidar_to_image_projector(xyz, R, t, K)
xy_norm, grid, mask = grid_generator(img_w, img_h, uv, depth)
Fi_point = image_sampler(fmap, grid)
    参数（Args）

    • lidar_points (torch.Tensor): LiDAR 点坐标张量，形状 (B, N, 3)；每个点为 (x, y, z)，坐标系需与 R,t 一致。

    • R (torch.Tensor): 外参旋转矩阵，形状 (B, 3, 3)；将点从 LiDAR 坐标系旋转到相机坐标系。

    • t (torch.Tensor): 外参平移向量，形状 (B, 3, 1)；将点从 LiDAR 坐标系平移到相机坐标系。

    • K (torch.Tensor): 相机内参矩阵，形状 (B, 3, 3)；将相机坐标系下的 3D 点投影到像素平面。

    返回（Returns）

    List[torch.Tensor]: [uv, depth, M] - uv: (B, N, 2)，像素坐标 (u, v)（单位：像素）。 - depth: (B, N, 1)，深度（相机坐标系 Z 分量），可用于过滤 depth > 0 的前向点。 - M: (B, 3, 4)，投影矩阵 M = K [R | t]。

    数学关系（Projection）

    对于齐次坐标 P_lidar = [x, y, z, 1]^T：

    M = K [R | t]     # 3x4
p = M @ P_lidar   # 3x1
depth = p_z
u = p_x / depth
v = p_y / depth

    其中 (u, v) 为像素坐标，depth 为相机坐标系 Z 值。

    注意事项（Notes）
    • 坐标系一致性：lidar_points 的坐标系必须与 R, t 的定义一致（常见为 LiDAR→Camera）。
    • 数值稳定：进行 u = px / z、v = py / z 时使用了 + 1e-6 以避免除零；若 depth ≤ 0，点位于相机后方，应在后续通过 mask 过滤。
    • 批处理支持：B 为 batch 维，所有输入需对齐到相同的 batch 大小。
    • 与下游接口：输出的 uv 与 depth 可直接传给 grid_generator(img_w, img_h, uv, depth)。

    @torch.library.custom_op("li_fusion::lidar_to_image_projector", mutates_args=[])
def lidar_to_image_projector(
    lidar_points: torch.Tensor,  # (B, N, 3)
    R: torch.Tensor,             # (B, 3, 3)
    t: torch.Tensor,             # (B, 3, 1)
    K: torch.Tensor              # (B, 3, 3)
) -> List[torch.Tensor]:
    """
    LiDAR → Image Projector（点云到图像投影算子）
    ==========================================

    将 LiDAR 三维点 **(x, y, z)** 投影到图像平面，依据相机外参 **R,t** 与内参 **K** 计算：
    - 像素坐标 `uv`（单位：像素）；
    - 深度 `depth`（相机坐标系下 Z 值）；
    - 投影矩阵 `M = K [R | t]`（3×4）。

    本算子属于 Li-Fusion **几何阶段** 的核心步骤，通常与 `grid_generator()`、`image_sampler()` 联用：
    ```python
    uv, depth, M = lidar_to_image_projector(xyz, R, t, K)
    xy_norm, grid, mask = grid_generator(img_w, img_h, uv, depth)
    Fi_point = image_sampler(fmap, grid)
    ```

    ---
    ### 参数（Args）
    - **lidar_points** (`torch.Tensor`):
      LiDAR 点坐标张量，形状 **(B, N, 3)**；每个点为 `(x, y, z)`，**坐标系需与 R,t 一致**。

    - **R** (`torch.Tensor`):
      外参旋转矩阵，形状 **(B, 3, 3)**；将点从 LiDAR 坐标系旋转到相机坐标系。

    - **t** (`torch.Tensor`):
      外参平移向量，形状 **(B, 3, 1)**；将点从 LiDAR 坐标系平移到相机坐标系。

    - **K** (`torch.Tensor`):
      相机内参矩阵，形状 **(B, 3, 3)**；将相机坐标系下的 3D 点投影到像素平面。

    ---
    ### 返回（Returns）
    List[`torch.Tensor`]: `[uv, depth, M]`
    - **uv**: `(B, N, 2)`，像素坐标 `(u, v)`（单位：像素）。
    - **depth**: `(B, N, 1)`，深度（相机坐标系 Z 分量），可用于过滤 `depth > 0` 的前向点。
    - **M**: `(B, 3, 4)`，投影矩阵 `M = K [R | t]`。

    ---
    ### 数学关系（Projection）
    对于齐次坐标 `P_lidar = [x, y, z, 1]^T`：
    ```
    M = K [R | t]     # 3x4
    p = M @ P_lidar   # 3x1
    depth = p_z
    u = p_x / depth
    v = p_y / depth
    ```
    其中 `(u, v)` 为像素坐标，`depth` 为相机坐标系 Z 值。

    ---
    ### 注意事项（Notes）
    - **坐标系一致性**：`lidar_points` 的坐标系必须与 `R, t` 的定义一致（常见为 LiDAR→Camera）。
    - **数值稳定**：进行 `u = px / z`、`v = py / z` 时使用了 `+ 1e-6` 以避免除零；若 `depth ≤ 0`，点位于相机后方，应在后续通过 `mask` 过滤。
    - **批处理支持**：`B` 为 batch 维，所有输入需对齐到相同的 batch 大小。
    - **与下游接口**：输出的 `uv` 与 `depth` 可直接传给 `grid_generator(img_w, img_h, uv, depth)`。

    """
    B, N, _ = lidar_points.shape
    device = lidar_points.device

    # Step 1: 齐次坐标
    ones = torch.ones((B, N, 1), device=device)
    lidar_homo = torch.cat([lidar_points, ones], dim=-1)  # (B, N, 4)

    # Step 2: 投影矩阵 M = K [R|t]
    Rt = torch.cat([R, t], dim=-1)                       # (B, 3, 4)
    M = torch.bmm(K, Rt)                                 # (B, 3, 4)

    # Step 3: 投影到相机平面
    uv_depth = torch.bmm(lidar_homo, M.transpose(1, 2))  # (B, N, 3)

    # Step 4: 提取 (u, v) 与 depth
    depth = uv_depth[..., 2:3]                           # (B, N, 1)
    u = uv_depth[..., 0] / (depth[..., 0] + 1e-6)        # (B, N)
    v = uv_depth[..., 1] / (depth[..., 0] + 1e-6)
    uv = torch.stack([u, v], dim=-1)                     # (B, N, 2)

    return [uv.clone(), depth.clone(), M.clone()]

    3. grid_generator

    生成归一化采样网格 grid:(B,1,N,2) 和有效掩码 mask:(B,N)。

    grid_generator(img_w, img_h, uv, depth)

    Li-Fusion Grid Generator（归一化采样网格生成算子）

    本算子是 Li-Fusion 几何阶段的关键模块之一，用于将 LiDAR 点投影到图像平面后， 生成与 torch.nn.functional.grid_sample 兼容的归一化采样网格 (grid)， 并计算有效点掩码 (mask)，以确定哪些投影点位于图像视野范围内。

    📘 算法原理

    对于每个 LiDAR 点投影后的像素坐标 (u, v) 以及对应深度 z： 1. 判断点是否有效（z > 0 且在图像尺寸范围内）； 2. 将 (u, v) 从像素坐标系映射到 [-1, 1] 区间； 3. 生成可供 grid_sample 使用的采样网格； 4. 输出三个张量：xy_norm, grid, mask。

    🧩 输入参数

    参数（Args）: img_w (int): 图像宽度（像素单位），用于将横向坐标归一化到 [-1, 1]。

    img_h (int):
    图像高度（像素单位），用于将纵向坐标归一化到 [-1, 1]。

uv (torch.Tensor):
    投影后的像素坐标，形状为 `(B, N, 2)`，每个点包含 `(u, v)`。

depth (torch.Tensor):
    深度值张量，形状为 `(B, N, 1)`，对应每个投影点的相机坐标系深度。
    📤 输出结果

    返回（Returns）: List[torch.Tensor]: 返回三个张量组成的列表 [xy_norm, grid, mask]： - xy_norm (B, N, 2)： 归一化的像素坐标，范围 [-1, 1]。 - grid (B, 1, N, 2)： 可直接传入 F.grid_sample 的采样网格。 - mask (B, N)： 有效点布尔掩码，满足 depth > 0 且投影落在图像范围内。

    ⚙️ 函数特性
    • 算子为无参算子，不参与反向传播；
    • 支持批处理输入；
    • 输出经过 .clone()，确保与输入不共享存储；
    • 用于 Li-Fusion 框架的几何阶段，与 image_sampler() 配合使用。
    🧠 示例
    xy_norm, grid, mask = torch.ops.li_fusion.grid_generator(
    img_w=1280, img_h=720, uv=uv_tensor, depth=depth_tensor
)
sampled_feature = F.grid_sample(image_feat, grid)
    📌 注意事项
    • 输入的 uv 与 depth 应来自 lidar_to_image_projector；
    • 若 uv 超出图像范围或深度为负，将在 mask 中被标记为无效；
    • 输出张量顺序固定为 [xy_norm, grid, mask]。

    @torch.library.custom_op("li_fusion::grid_generator", mutates_args=[])
def grid_generator(img_w: int, img_h: int, uv: torch.Tensor, depth: torch.Tensor) -> List[torch.Tensor]:
    """
    Li-Fusion Grid Generator（归一化采样网格生成算子）
    ==================================================

    本算子是 Li-Fusion 几何阶段的关键模块之一，用于将 LiDAR 点投影到图像平面后，
    生成与 `torch.nn.functional.grid_sample` 兼容的归一化采样网格 (`grid`)，
    并计算有效点掩码 (`mask`)，以确定哪些投影点位于图像视野范围内。

    ---
    ### 📘 算法原理

    对于每个 LiDAR 点投影后的像素坐标 `(u, v)` 以及对应深度 `z`：
    1. 判断点是否有效（`z > 0` 且在图像尺寸范围内）；
    2. 将 `(u, v)` 从像素坐标系映射到 [-1, 1] 区间；
    3. 生成可供 `grid_sample` 使用的采样网格；
    4. 输出三个张量：`xy_norm`, `grid`, `mask`。

    ---
    ### 🧩 输入参数

    参数（Args）:
        img_w (int):
            图像宽度（像素单位），用于将横向坐标归一化到 [-1, 1]。

        img_h (int):
            图像高度（像素单位），用于将纵向坐标归一化到 [-1, 1]。

        uv (torch.Tensor):
            投影后的像素坐标，形状为 `(B, N, 2)`，每个点包含 `(u, v)`。

        depth (torch.Tensor):
            深度值张量，形状为 `(B, N, 1)`，对应每个投影点的相机坐标系深度。

    ---
    ### 📤 输出结果

    返回（Returns）:
        List[torch.Tensor]:
        返回三个张量组成的列表 `[xy_norm, grid, mask]`：
        - **xy_norm** `(B, N, 2)`：
          归一化的像素坐标，范围 [-1, 1]。
        - **grid** `(B, 1, N, 2)`：
          可直接传入 `F.grid_sample` 的采样网格。
        - **mask** `(B, N)`：
          有效点布尔掩码，满足 `depth > 0` 且投影落在图像范围内。

    ---
    ### ⚙️ 函数特性

    - 算子为无参算子，不参与反向传播；
    - 支持批处理输入；
    - 输出经过 `.clone()`，确保与输入不共享存储；
    - 用于 Li-Fusion 框架的几何阶段，与 `image_sampler()` 配合使用。

    ---
    ### 🧠 示例

    ```python
    xy_norm, grid, mask = torch.ops.li_fusion.grid_generator(
        img_w=1280, img_h=720, uv=uv_tensor, depth=depth_tensor
    )
    sampled_feature = F.grid_sample(image_feat, grid)
    ```

    ---
    ### 📌 注意事项

    - 输入的 `uv` 与 `depth` 应来自 `lidar_to_image_projector`；
    - 若 `uv` 超出图像范围或深度为负，将在 `mask` 中被标记为无效；
    - 输出张量顺序固定为 `[xy_norm, grid, mask]`。
    """
    W, H = img_w, img_h

    # 避免直接对 uv 的视图进行后续计算，先拷贝一份（可选但更稳）
    u = uv[..., 0].contiguous()         # 或 uv[..., 0].clone()
    v = uv[..., 1].contiguous()

    valid_depth = (depth[..., 0] > 0)
    valid_u = (u >= 0) & (u <= (W - 1))
    valid_v = (v >= 0) & (v <= (H - 1))
    mask = (valid_depth & valid_u & valid_v)

    u_norm = (u / (W - 1.0)) * 2.0 - 1.0
    v_norm = (v / (H - 1.0)) * 2.0 - 1.0
    xy_norm = torch.stack([u_norm, v_norm], dim=-1).contiguous()
    grid = xy_norm.unsqueeze(1).contiguous()

    # 关键：返回前做 clone，确保与输入不共享存储
    return [xy_norm.clone(), grid.clone(), mask.clone()]

    4. image_sampler

    利用 grid_sample 在图像特征图上采样每个点的图像特征，实现几何级融合。

    image_sampler(feature_map, grid)

    Li-Fusion Image Sampler（图像特征采样算子）

    在图像特征图上，依据几何阶段生成的采样网格 grid 执行双线性插值， 为每个投影到图像平面的 3D 点提取对应的图像特征，实现点云与图像的逐点对齐。

    该算子是 Li-Fusion 几何对齐 → 融合流程中的最后一个几何步骤， 常与 grid_generator 联用：grid = grid_generator(...)[1]。

    参数（Args）: feature_map (torch.Tensor): 图像特征图，形状 (B, C, H, W)。 - B：batch 大小 - C：特征通道数 - H/W：特征图高/宽（通常与骨干网络的输出分辨率一致）

    grid (torch.Tensor):
    归一化采样网格，形状 `(B, 1, N, 2)`，数值范围 `[-1, 1]`。
    - 由 `grid_generator` 基于像素坐标 `(u, v)` 与图像尺寸生成
    - 末维顺序为 `(x_norm, y_norm)`，对应 `(u_norm, v_norm)`
    - 第二维固定为 `1`，表示按点集（长度 `N`）采样

    返回（Returns）: torch.Tensor: 采样得到的逐点图像特征，形状 (B, C, N)。 其中 N 为有效/无效点的总数（可配合 mask 进一步筛选）。

    Notes
    • 内部调用 torch.nn.functional.grid_sample，并设定 align_corners=True。
    • 若某些点超出 [-1,1] 或深度无效，grid_sample 会返回边界/零值； 因此通常结合 mask 过滤无效点（mask 由 grid_generator 提供）。
    • 返回前使用 .clone() 保证与输入不共享存储，满足自定义算子返回约束。

    @torch.library.custom_op("li_fusion::image_sampler", mutates_args=[])
def image_sampler(feature_map: torch.Tensor, grid: torch.Tensor) -> torch.Tensor:
    """
    Li-Fusion Image Sampler（图像特征采样算子）
    =========================================

    在图像特征图上，依据几何阶段生成的采样网格 `grid` 执行**双线性插值**，
    为每个投影到图像平面的 3D 点提取对应的图像特征，实现点云与图像的**逐点对齐**。

    该算子是 Li-Fusion 几何对齐 → 融合流程中的**最后一个几何步骤**，
    常与 `grid_generator` 联用：`grid = grid_generator(...)[1]`。

    参数（Args）:
        feature_map (torch.Tensor):
            图像特征图，形状 `(B, C, H, W)`。
            - **B**：batch 大小
            - **C**：特征通道数
            - **H/W**：特征图高/宽（通常与骨干网络的输出分辨率一致）

        grid (torch.Tensor):
            归一化采样网格，形状 `(B, 1, N, 2)`，数值范围 `[-1, 1]`。
            - 由 `grid_generator` 基于像素坐标 `(u, v)` 与图像尺寸生成
            - 末维顺序为 `(x_norm, y_norm)`，对应 `(u_norm, v_norm)`
            - 第二维固定为 `1`，表示按点集（长度 `N`）采样

    返回（Returns）:
        torch.Tensor:
            采样得到的逐点图像特征，形状 `(B, C, N)`。
            其中 `N` 为有效/无效点的总数（可配合 `mask` 进一步筛选）。

    Notes:
        - 内部调用 `torch.nn.functional.grid_sample`，并设定 `align_corners=True`。
        - 若某些点超出 `[-1,1]` 或深度无效，`grid_sample` 会返回边界/零值；
          因此通常结合 `mask` 过滤无效点（`mask` 由 `grid_generator` 提供）。
        - 返回前使用 `.clone()` 保证与输入不共享存储，满足自定义算子返回约束。
    """
    sampled = F.grid_sample(feature_map, grid, align_corners=True)  # (B, C, 1, N)
    sampled = sampled.squeeze(2).contiguous()
    return sampled.clone()
